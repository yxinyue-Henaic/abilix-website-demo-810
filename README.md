# Abilix PartnerX Website Demo

A dependency-free, responsive implementation of `Abilix PartnerX Website Prototype0806.pdf`.

## Run

1. Install Node.js 18 or later.
2. Run `npm start` in this folder.
3. Open `http://localhost:4173`.

You can also open `index.html` directly. Navigation uses hash routes, so no server rewrites are required.

## Pages and interactions

- Home: navigation, CTAs, solution links and product carousel.
- Products: age filters, carousel controls, favorites and product-detail navigation.
- Curriculum: interactive learning-path accordion.
- WER: external-site CTA opens in a new tab.
- Solutions: accessible vertical tabs with image and copy transitions.
- Resources: live search across resource cards.
- Xiaoxing: image gallery, quantity control, add-to-bag feedback and recommendations.

Source artwork was copied at build time from `E:\...能力风暴PartnerX\Web_Design\web_images`; the four Solutions images came from the supplied `abilix-solutions-vertical-tabs-local` reference project.
